Dynamic Programming: From Recursion to Efficient Solutions
TEACHER MATERIALS - LESSONS 1-5

Teacher Book (teacher-book.pdf): detailed preparation, reasoning, worked examples, diagrams and complete implementations.
Teacher Class Notes (teacher-class-notes.pdf): classroom timings, questions, hints, solutions, traces and complete code.

Both volumes have linked contents and continuous page numbering. Question IDs match the lesson worksheets, slides and notebooks.

Edit the generators in Course source/, then run python3 -B build_teacher_books.py and python3 -B publish.py there. Do not hand-edit generated TeX.
To compile a saved volume directly, run XeLaTeX three times from this folder on its .tex file. main.tex selects Teacher Book.
